Let the clinic set its own social links

The handles were in config/clinic.php, so changing one meant a deployment
and the same value for every installation that shares the code. There was
nowhere in the office to type a handle, which is the only place anybody
running a clinic would look.

They are saved per organisation now and drawn into the footer. A full
profile url is accepted as well as a handle, because that is what somebody
pastes from their browser bar, and the alternative is a footer link to
facebook.com/https://facebook.com/patrice. Anything that would build a
broken link is refused rather than published, and a cleared box removes the
link instead of leaving an empty one behind.

The config remains the fallback, so an installation that has never opened
the screen still shows what it was deployed with.
